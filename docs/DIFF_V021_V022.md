# Cambios V0.2.1 → V0.2.2

Comparación: `git diff v0.2.1..v0.2.2`. Sin cambios de arquitectura: mismos Vercel, Supabase PostgreSQL, Hono, React y Vite. Sin dependencias nuevas en tiempo de ejecución.

| Área | Antes (V0.2.1) | Ahora (V0.2.2) |
| :- | :- | :- |
| Tarjeta en el teléfono | Solo en el navegador | Se agrega a la pantalla de inicio (PWA) en iPhone y Android |
| Manifiesto e íconos | No había | Por negocio: nombre, color, ícono con su inicial, `id` y `scope` propios |
| Service worker | No había | Propio, solo cachea recursos públicos; nada de API ni enlaces personales |
| App instalada sin cookie | — | Código de 8 dígitos de un solo uso o enlace personal |
| Sin conexión | Error genérico | Aviso claro; no muestra sellos inventados ni deja operar |
| Base de datos | Migraciones 0001–0004 | + 0005 `card_pair_codes` con RLS por negocio |
| Acceso de clientes | Preview protegido con login de Vercel | Demo pública aparte (`vlux-loyalty-demo`); interno sigue protegido |
| Pruebas | Integración 49, E2E Chromium | Integración 58, E2E PWA en Chromium, WebKit y Firefox (CI), verificación HTTPS en Vercel |
| Documentación | — | `ACCESO_VERCEL_V022.md`, `PWA_INVESTIGACION_V022.md`, `INFORME_SEGURIDAD_V022.md`, `calidad/atomos-v022.md`, checklist físico con PWA, respaldos con estado real |

Archivos de código cambiados: `server/app.ts`, `server/index.ts`, `server/pwa.ts` (nuevo), `server/services/pairing.ts` (nuevo), `src/lib/pwa.ts` (nuevo), `src/components/SaveCard.tsx` (nuevo), `src/sw/sw-template.js` (nuevo), `src/views/Customer.tsx`, `src/main.tsx`, `src/styles.css`, `vite.config.ts`, `scripts/build-vercel.mjs`, `ops/grants.sql`, `db/migrations/0005_*`.

Lo que **no** cambió: autenticación de personal, reglas de sellos y canjes, panel del dueño, Production (sigue bloqueado), visibilidad del repositorio (pública), Apple Wallet y Google Wallet (no incluidos).
